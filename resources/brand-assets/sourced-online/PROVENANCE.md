# Logos sourced from the affiliated companies' own sites

Downloaded because the client asked for "all logos wherever necessary" and
these entities have no artwork in the local brand folders.

| Shipped as | Source |
|---|---|
| `kc-space-academy.webp` | `kcsa.org.in/resources/images/kcsa/secoundry-logo.png` |
| `mobilepe-topay.webp` | `topay.live/assets/img/logo/logo.png` |

Both already carried real alpha channels, so no background removal was
needed — only resize, trim and WebP re-encode.

**KCSA:** the site's *primary* logo (`opt-logo.png`) sets "Kalpana Chawla
Space Academy" in dark navy, which disappears against this site's near-black
background. The secondary wordmark is used instead.

**MobilePe:** the mark reads "ToPay", which is MobilePe Fintech's live
consumer platform rather than the company name. Used on the MobilePe
Fintech card, and the card's role line names ToPay so the two connect.
Swap it if the client would rather show a MobilePe corporate mark.
